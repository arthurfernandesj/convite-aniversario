# Baile de Máscaras – Arthur Fernandes

Convite digital. Todos os textos estão em `src/data/invite.ts`.

## ⚠️ Antes de publicar, troque em `src/data/invite.ts`
- `GROUP_URL` → link do grupo do WhatsApp
- `WHATSAPP_NUMBER` → seu número (55 + DDD + número, só dígitos)

## Como rodar
```
npm install
npm run dev      # abrir no navegador para testar
npm run build    # gera a pasta dist/ para publicar (Netlify, Vercel, etc.)
```
